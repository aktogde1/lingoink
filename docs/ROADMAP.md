# LingoInk — roadmap

> Обновлено 2026-09-26: актуальные изменения учебного цикла, даты, повторов и прогресса описаны в [LEARNING_UPDATE.md](LEARNING_UPDATE.md). При расхождении старого описания с обновлением действует обновление.

## Текущее состояние: v0.3.2-beta (2026-09-27)

v0.1 (MVP): boot+детект железа (X3/X4, партии панелей), SD, каталог
курсов, загрузка уроков (choice/cloze/mistake/reading + theory), SRS
SM-2 + mastery по тегам, прогресс на SD с resume, экраны Home/Lesson/
Progress, refresh «fast везде + full на выключении», сэмпл-курс.
Отвалидировано на железе (частично, см. HARDWARE_VALIDATION.md).

В v0.3.0-beta дополнительно: учебное обновление 2026-09-26 (очередь
повторов, ручная дата, задания на вспоминание, пагинация чтения —
см. LEARNING_UPDATE.md), карточка выключения в артворке сплэша со
строкой «Заряд N%» (свежий замер перед сном) и главное меню из 5
пунктов, которое помещается на экране целиком во всех ориентациях
(низ меню очищен: батарея и дубль курса убраны).

Ветка `learning8` (2026-09-26, качество обучения): дата подтверждается
один раз за включение; «Повторить» — одна очередь до 12 заданий из всех
изученных уроков; трёхуровневая честная самооценка recall (вспомнил /
с подсказкой / не вспомнил); курс доведён до 40.2% активного
воспроизведения (107/266 повторяемых), SRS-ядро покрыто на 79%;
«уже знаю: проверить» на новых уроках. Детали и точная логика оценок —
LEARNING_UPDATE.md.

v0.2 — UX и ощущение законченного устройства:

1. **Portrait 480×800 + Landscape 800×480**: переключение в Settings,
   сохраняется в progress.json; отдельные layout-метрики на ориентацию;
   без второго framebuffer (трансформация координат в Canvas).
2. **Settings**: ORIENTATION, SCREEN CLEAN (Manual/Auto), AUTO CLEAN
   (Off/20/40), CLEAN SCREEN NOW, RESET PROGRESS (+подтверждение).
3. **Перемешивание вариантов** при входе в упражнение (проверка по
   исходному answer key; формат JSON не менялся); sample-курс больше не
   держит `correct` искусственно на 0.
4. **Честный Back**: никогда не «далее»; по фазам — назад по страницам,
   «EXIT LESSON?» (lastLessonId не двигается), из Settings/Progress — Home.
5. **Явный feedback**: CORRECT/WRONG + правильный ответ + короткое
   объяснение; дальше только OK; полный `explain` — paging-ридер по
   long-OK (ничего не обрезается).
6. **Батарея** на Home (BatteryMonitor, процент + иконка, скрыт если
   телеметрия недоступна).
7. **Фиксы UX**: скроллящееся окно вариантов (нет невидимых 5–6),
   перенос длинных вариантов/prompts, фидбек привязан к выбранной строке,
   фейковые метрики скрыты (REVIEW убран, streak и Production скрыты).
8. **Новая главная («меню игры», выбран вариант Б)**: 4 пункта
   (УЧИТЬСЯ / УРОКИ И ТЕМЫ / ПРОГРЕСС / НАСТРОЙКИ) с подписями;
   оглавление уроков со статусами ✓/• и группировкой по уровням;
   полоса дневной цели убрана; отметки пройденных уроков (doneMask).

Не закрыто в v0.2 (осознанно): настоящая REVIEW-сессия, streak-логика,
индикатор прогресса уровня, мультивыбор курсов, портретная эргономика
кнопок (проверить на железе), выбор курса при нескольких на карте,
экран ошибки SD.

## v0.2.x — качество и детализация интерфейса

1. **Слой хрома** (`ui/Chrome.h` + метрики в `config.h`): единые шапка с
   линейкой и счётчиком, скролл-хинты в углу, скруглённое выделение,
   пунктирные разделители, один стиль модалок (очистка экрана, карточка
   r=20, pill-кнопки), пилюли-прогресс, чипы слабых мест, виджет батареи —
   магические числа в экранах уничтожены.
2. **Canvas-примитивы**: roundRect/roundFrame (гладкие углы: заливка +
   выемка), пунктир, blit 1-bpp битмапов; шрифт display56 (Inter Bold).
3. **Экраны**: Home с шапкой из манифеста (язык + трек уровней «A2 → B1»),
   Lessons с колонками и группировкой по дням, Lesson без букв у
   вариантов (длинные переносятся до 3 строк — ничего не обрезается),
   крупный процент в Summary, Progress с «—» вместо фейковых 0%,
   Settings на общем хроме.
4. **Host-превью** (`tools/preview/`): рендер всех экранов в PNG без
   прошивки (те же Canvas/Chrome; шимы не попадают в прошивку) — первая
   половина «превью на эмуляторе канваса» из Web studio.
5. **Строки**: захардкоженные выносы из экранов в Strings.h; glyphs
   (✓/✗/→/•) — именованные константы; Nav→Refresh — одно правило в App.

## v0.2.y — ревизия UX по feedback с железа

1. **Power**: выключение только удержанием (~1 с), короткое нажатие =
   подтверждение (как OK). Wake — как раньше, кнопкой Power.
2. **Ориентация**: единственная — Портрет 180° (пункт ORIENTATION из
   Settings удалён; `orient` в progress.json игнорируется).
3. **Низ экрана**: строки-подсказки и линия убраны — контенту +40 px;
   внизу только батарея и `^`/`+N`.
4. **Циклический скролл** всех списков (Home/Lessons/Settings/варианты).
5. **Шрифт**: ui22 (Inter SemiBold 22px) вместо тонкого ui20 — читаемость
   на 1-bpp панели; жирные акценты в списках.
6. **Длинные строки в фокусе** разворачиваются (2 строки меню/уроки,
   3 строки варианты) — без бегущих строк, которые на e-ink невозможны.
7. **Честные метрики**: «N к повторению» и «Слабые места» скрыты, пока
   пусты; навык без данных — «—», не 0%.
8. **Карточка выключения**: тот же артворк, что и сплэш при включении —
   крупное «LingoInk» (Display) + «Английский · Русский» +
   «Один экран. Одна цель».

## v0.3 — content & exercises

1. **REVIEW = настоящая сессия повторения**: выбор due-items +
   приоритет упражнений слабых тегов (механика mastery уже готова).
2. **Честный счёт дней и streak**: инкремент при достижении цели дня,
   сброс при пропуске (дни уже считаются по uptime); вернуть streak в UI.
3. **Production skill**: типы упражнений с реальной продукцией, чтобы
   четвёртая полоса навыков ожила.
4. **Контент**: полный сэмпл-курс A2 (~20 уроков), чтобы v0.3 можно
   было проходить неделями.
5. Тип `build` (sentence builder) и/или `dialogue` (формат уже
   зарезервирован в COURSE_FORMAT.md).
6. Приоритизация упражнений по weak tags внутри обычных уроков.
7. Валидатор курсов на хосте (линтер JSON против спецификации).
8. Экран ошибки SD + выбор курса при нескольких на карте.

## Дистрибуция: прошиваемость как у CrossPoint-форков (план, 2026-09-26)

Флешеры семейства CrossPoint (веб-флешер, Papyrix, Inky) рассчитаны на
заводскую таблицу разделов X4 с app1 (ota_1) @ 0x650000 — OTA-слот для
их схемы обновлений. В таблице LingoInk app1 выкинут, поэтому поверх
LingoInk эти флешеры не работают — нужен предварительный возврат к
стоку. Проверено на железе 2026-09-26: сток → CrossInk v1.6.0 и
InkPointX v2.3.6 ставятся штатно (app0 @ 0x10000 + otadata 0xFF).

Чтобы LingoInk ставился и снимался так же легко, как форки:

1. Вернуть app1 (ota_1) в partitions.csv: app1 @ 0x650000, 0x640000
   (spiffs не двигается: 0xC90000 / 0x360000 — как у CrossPoint/CrossInk).
2. Публиковать релизы как у форков: firmware.bin (образ app0) +
   SHA256SUMS + SD-пак курса; манифест ESP-web-tools для веб-флешера.
3. Попасть в каталоги флешеров (Inky, Papyrix): общий загрузчик и
   совпадающий layout на freeink-sdk это позволяют.
4. Двусторонняя инструкция перехода LingoInk ↔ CrossPoint-семейство
   без восстановления стока (запись app0 + otadata).

## Дальнейшие этапы

- Больше языковых пар (en→es, de→ru…), мультикурсовый UI.
- Локализация хрома UI (сейчас английский).
- Генерация паков упражнений по слабостям (офлайн-инструмент).

## Wi-Fi (отдельный milestone, после v0.3)

Только сервисные функции, не соцсеть: загрузка курсов с сервера,
бэкап прогресса, OTA. NTP → wall-clock дни для SRS (замена
uptime-подсчёта, миграция прозрачная — поле day уже есть).
SecureNet/wolfSSL уже есть в freeink-sdk.

## Sync

Двусторонняя синхронизация прогресса между устройствами/вебом
(conflict resolution по last-write; формат progress.json v1 уже
носит всё нужное).

## Web studio

Редактор курсов в браузере: authoring уроков, превью на эмуляторе
канваса, публикация паков на SD/сервер. Курс — просто JSON, студия
не требует участия прошивки.

## AI

- Генерация упражнений по слабым тегам из mastery-статистики
  (формат `srs[]`/`tags[]` это уже поддерживает).
- Авторский ассистент в web studio (черновики уроков по теме уровня).
- На устройстве AI не исполняется никогда — только контент.

## Принцип приоритетов

Железо и валидация → качество обучения (REVIEW, слабые места) →
контент → только потом сеть/студия/AI.
