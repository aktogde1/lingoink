# LingoInk — hardware (XTEINK X4)

> Обновлено 2026-09-26: актуальные изменения учебного цикла, даты, повторов и прогресса описаны в [LEARNING_UPDATE.md](LEARNING_UPDATE.md). При расхождении старого описания с обновлением действует обновление.

## Платформа

| Компонент | Значение |
|---|---|
| SoC | ESP32-C3, RISC-V, 1 ядро 160 МГц |
| RAM | 400 KB SRAM, ~380 KB heap, **без PSRAM** |
| Flash | 16 MB; app0 6.4 MB @ 0x10000 (layout совместим с CrossPoint) |
| Дисплей | 4.3" e-ink **800×480**, 1-bpp, без подсветки |
| Контроллер панели | SSD1677 (основной); партии UC8179/UC8279 — автоопределение пробой при boot |
| Touch | нет — только физические кнопки |
| Батарея | 650 mAh, ADC-гейдж на GPIO0 (индикатор в UI пока не выведен) |
| USB | USB-C CDC: логи 115200 + прошивка esptool |

Кнопки — ADC-лестница, дребезг фильтрует InputManager SDK:
Back/OK/Left/Right на GPIO1; Up/Down (боковые) на GPIO2; Power на GPIO3.
Нюанс (проверено на железе 2026-09-26): две правые кнопки нижнего ряда
декодируются лестницей инверсно их физическому расположению — правая
крайняя шлёт BTN_LEFT; InputLoop свапает их, так что правая физическая
кнопка всегда означает «вперёд/вниз».
Питание: power-latch GPIO13; выключение = rails off + deep sleep,
пробуждение только кнопкой Power (cold boot).

## Разводка (BoardConfig freeink-sdk — источник истины)

| Назначение | Пины |
|---|---|
| Display SPI | SCLK=8, MOSI=10, CS=21, DC=4, RST=5, BUSY=6 |
| SD SPI (общая шина) | SCLK=8, MOSI=10, MISO=7, CS=12 |
| Кнопки | GPIO1 (лестница), GPIO2 (Up/Down), GPIO3 (Power) |
| Батарея ADC | GPIO0 |
| Power latch | GPIO13 |

## Разделы flash (partitions.csv)

```
nvs      0x9000   0x5000   ← калибровка панели; НЕ стирать
otadata  0xE000   0x2000
app0     0x10000  0x640000 ← сюда шьётся LingoInk (единственный offset)
spiffs   0xC90000 0x360000
coredump 0xFF0000 0x10000
```

Прошивка пишет **только app0 @ 0x10000** поверх стока/CrossPoint.
`erase_flash` запрещён. Backup полного flash перед первой прошивкой —
обязательно (команды в README).

## Бюджет памяти (критично: без PSRAM)

| Буфер | Размер | Где |
|---|---|---|
| Canvas 1-bpp 800×480 | 48 KB | BSS (статический) |
| Panel framebuffer | ~48 KB | heap, **аллоцируется первым при boot** |
| App + LessonScreen (Lesson ~26 KB) | ~90 KB | heap, после framebuffer |
| JSON-буфер урока | 36 KB | BSS |
| Свободный heap после init | ~120 KB | — |

Порядок boot (main.cpp) менять нельзя: serial → XteinkDetect → probe
панели → SPI+SD **до** дисплея → display.begin() (framebuffer первым) →
App. Нарушение порядка = проверенные на железе баги (SD не монтируется /
framebuffer NULL → panic).

## Ограничения, которые диктуют дизайн

- **E-ink**: никаких анимаций/миганий; FAST DU ~85 мс на обновление,
  FULL — секунды и только на выключении; ghosting чистится FULL-кадром
  выключения. Дифференциальные обновления против «замороженного» кадра.
- **Один поток UI**: весь loop в одном цикле Arduino, никаких задач.
- **Heap мал**: всё статическое; heap только на boot (framebuffer, App)
  и короткоживущие JSON-буферы чтения SD. Новые фичи обязаны
  вписываться в ~120 KB свободного heap без фрагментации.
- **Нет RTC/сети**: пользователь подтверждает календарную дату перед занятием; uptime больше не влияет на SRS.
- **Общая SPI-шина дисплея и SD** — SD монтируется до инициализации
  дисплея; вставлять карту до включения.
- **Партии панелей различаются** (SSD1677/UC8179/UC8279) — любую правку
  display-кода проверять через probe (`applyXteinkDisplayController`),
  не хардкодить контроллер.
- **USB-locked партии (AliExpress)**: шить только app0; устройства
  покупать на xteink.com (см. TECHNICAL_PLAN § Risks).
- **X4 Pro / X3** — другие платы; X3 поддержан кодом (detect), X4 Pro
  вне MVP, но HAL freeink-sdk его допускает.
