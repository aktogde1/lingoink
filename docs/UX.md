# LingoInk — UX

> Обновлено 2026-09-26: актуальные изменения учебного цикла, даты, повторов и прогресса описаны в [LEARNING_UPDATE.md](LEARNING_UPDATE.md). При расхождении старого описания с обновлением действует обновление.

## Управление (кнопки X4)

GPIO1 ADC-лестница: Back, OK, Left, Right; GPIO2 (боковые): Up, Down;
GPIO3: Power.

| Кнопка | Действие |
|---|---|
| Left / Up | выделение вверх (циклично: с первого — на последний) |
| Right / Down | выделение вниз (циклично: с последнего — на первый) |
| OK | подтвердить ответ / далее |
| OK удержание (600 мс) | полное объяснение (paging-ридер) |
| Power короткое | подтвердить выбор — как OK |
| Power удержание (~1 c) | выключение (карточка-заставка, как при включении + deep sleep) |
| Back | назад; никогда не означает «далее» (см. Back) |

Выключение — только удержанием Power; случайное короткое нажатие просто
подтверждает текущий выбор. Пробуждение — кнопка Power (холодный boot).

Один экран = один контекст; двойных срабатываний нет (дребезг фильтрует
InputManager SDK, длинные нажатия синтезируются в InputLoop).

### Back — семантика по экранам

| Экран | Back |
|---|---|
| Home | ничего (верхний уровень) |
| Settings / Progress | → Home |
| Theory / Reading | предыдущая страница; на первой — «EXIT LESSON?» |
| Exercise (до ответа) | «EXIT LESSON?» |
| Exercise (после ответа) | ничего (feedback не пропускается) |
| Explanation reader | закрыть |
| Диалог «EXIT LESSON?» | отмена, остаться в уроке |

Выход из урока («EXIT LESSON?», OK — exit / BACK — cancel): `lastLessonId`
не двигается (урок останется «текущим»), прогресс и SRS-результаты уже
данных ответов сохраняются честно.

## Навигация по экранам

```
Splash → Home (главное меню)
  Home ─ УЧИТЬСЯ      → Lesson (следующий непройденный урок)
  Home ─ ПОВТОРИТЬ    → одна очередь из-за 12 заданий из всех изученных уроков
  Home ─ УРОКИ И ТЕМЫ → Lessons (оглавление) ─ OK → Lesson
  Home ─ ПРОГРЕСС     → Progress ─ OK/Back → Home
  Home ─ НАСТРОЙКИ    → Settings ─ Back → Home
  Lesson/Progress/Settings ─ Back → Home
```

- **Дата** подтверждается один раз за включение — перед первым учебным
  действием; дальше в этой сессии уроки и повторы стартуют сразу.
  Ручной редактор даты остаётся в Settings; после перезагрузки дата
  спрашивается снова; движение даты назад запрещено.
- **Home** — главное меню из 5 пунктов, у каждого подпись «что это»:
  УЧИТЬСЯ (Продолжить: <урок> · N из M) / ПОВТОРИТЬ (N к повторению) /
  УРОКИ И ТЕМЫ / ПРОГРЕСС (Навыки и слабые места) / НАСТРОЙКИ
  (Язык, экран, ориентация). Шапка: название языка (первое слово title
  манифеста) + трек уровней «A2 → B1» из `levels` манифеста (нет поля —
  текущий уровень). Низ меню чистый: батареи и дублирующей подписи
  курса нет (заряд показывается на карточке выключения). Все 5 пунктов
  видны одновременно без прокрутки: межстрочные зазоры считаются из
  доступной высоты (метрики в config.h). Длинный сабтитл выбранного
  пункта разворачивается в 2 строки, пока влезает, иначе — одна строка
  с многоточием; строки никогда не перекрываются (без анимаций — e-ink
  не умеет частичные обновления).
- **Lessons (оглавление)**: все уроки с номерами и статусами
  (✓ пройден, • сейчас = следующий непройденный), сгруппированы по
  уровням из манифеста («День 1…7»); листается циклически (^ / +N в
  правом нижнем углу); OK — начать урок, Back — в меню. Отметка
  «пройден» ставится в конце урока (не при выходе через EXIT) и хранится
  в `doneMask` progress.json. Колонки: номер (по правому краю),
  название, статус у края; выбранный длинный заголовок разворачивается
  на 2 строки.
- **Theory**: заголовок + счётчик «ПРАВИЛО N/M» в шапке, строки правила,
  OK/Down — листать экранами, Back/Up/Left — назад по страницам; на
  первой странице — выход.
- **Reading**: заголовок + счётчик «СТРАНИЦА N/M» в шапке, страница
  текста, Down/OK — далее, Back/Up — назад; после последней страницы —
  вопросы (choice с тегом `reading`).
- **Exercise**: инструкция в слоте шапки (ВЫБЕРИТЕ ВАРИАНТ/ПЕРЕВЕДИТЕ/
  ЗАПОЛНИТЕ ПРОПУСК/НАЙДИТЕ ОШИБКУ/ВОПРОС — язык обвязки) + счётчик
  «упр. N из M» справа, prompt, варианты столбиком. Варианты
  перемешиваются при входе в упражнение и не меняются до конца вопроса;
  проверка — по исходному answer key из JSON. Выбор листается циклически;
  длинные варианты переносятся до 3 строк — текст никогда не обрезается
  молча. Если варианты не помещаются — скроллящееся окно с индикаторами
  `^` / `+N` в правом нижнем углу.
- **Gate («УЖЕ ЗНАЕТЕ?»)**: новый, ещё не открытый урок начинается с
  выбора — ПРОЙТИ УРОК (теория и все задания) или УЖЕ ЗНАЮ: ПРОВЕРИТЬ
  (до 5 ключевых заданий без теории, recall в приоритете). Проверка
  оценивается как обычный урок; при ≥80% верных первых ответов урок
  отмечается освоенным, при слабом результате предлагается пройти урок
  целиком. Возобновлённые уроки и повторы гейт не показывают.
- **Recall (самооценка из трёх исходов)**: после показа ответа — меню
  НЕ ВСПОМНИЛ (ошибка, lapse) / С ПОДСКАЗКОЙ (частично или с помощью:
  интервал не растёт, возврат завтра, мягче провала) / ВСПОМНИЛ (успех,
  только если помощь не открывалась — иначе засчитывается как подсказка).
  Курсор по умолчанию на «НЕ ВСПОМНИЛ» — случайное подтверждение не
  превращается в фиктивный успех.
- **Feedback** (после ответа): у выбранного варианта остаётся инверсия и ✗
  (или ✓, если верно), у правильного — ✓; ниже — скруглённая карточка:
  ВЕРНО/ОШИБКА, `ответ: …` (при ошибке) и короткое объяснение. Дальше
  только OK — случайные нажатия не пропускают feedback.
- **Explanation reader** (удержание OK): полный текст `explain` по
  страницам (счётчик «СТРАНИЦА N/M» в шапке), OK/Down — далее, Back —
  закрыть. Объяснения никогда не обрезаются молча.
- **Summary**: крупный процент шрифтом Display + «ВЕРНО», число верных
  ответов → OK — home. Для повторов итог считается по всей очереди
  (до 12 заданий из разных уроков), слайсы сцепляются без промежуточных
  итогов.
- **Progress**: 3 пилюли-полосы навыков на всю ширину (Словарь /
  Грамматика / Чтение); навык без данных — «—» и пустая пилюля (никаких
  фейковых 0%). «Слабые места» (чипы) и «N к повторению» показываются
  только когда заполнены реальными данными. OK/Back — home. Production
  и streak не показываются, пока не заполняются реальными данными.

## Settings

Пункт Home-меню SETTINGS:

| Пункт | Значения |
|---|---|
| LANGUAGE | English / Русский (язык обвязки UI; по умолчанию Русский) |
| CLEAN SCREEN NOW | один FULL refresh, возврат в Settings |
| RESET PROGRESS | модальный диалог «СБРОС ПРОГРЕССА?» (OK — сброс, ОТМЕНА — отмена) |
| BACK | → Home |

ORIENTATION и AUTO CLEAN удалены по решению пользователя: устройство
всегда работает в «Портрет 180°» (единственная ориентация, поле `orient`
в progress.json игнорируется), а авто-очистка не нужна — панель
освежается на карточке выключения и по CLEAN SCREEN NOW. Старые
progress.json совместимы: неизвестные поля игнорируются.

RESET PROGRESS стирает только `/lingoink/progress.json` (SRS, mastery,
resume-указатель, счётчики и настройки → заводские значения). Курсы на SD
не затрагиваются.

## Визуальный язык (chrome)

Единый набор правил отрисовки живёт в `src/ui/Chrome.h` и метриках
`config.h` — экраны не придумывают свои отступы. Все элементы статичные
(e-ink: без анимаций и полутонов).

- **Шапка** — заголовок (title36) слева, мелкая подпись справа по базовой
  линии заголовка (счётчики «ПРАВИЛО N/M», «упр. N из M», трек уровней),
  под ними тонкая сплошная линия. Слишком длинный заголовок укорачивается
  «…» до свободного места.
- **Низ экрана** — никаких строк-подсказок и линии: только батарея (Home)
  и индикаторы скролла `^`/`+N` в правом нижнем углу. Контент получает
  всю высоту до зоны виджетов.
- **Выделение строки** — одна трактовка: залитая скруглённая карточка
  (радиус 10) шире колонки текста + инверсный текст. Длинная строка в
  фокусе разворачивается на 2 строки (меню/уроки) или 3 (варианты) —
  полный текст, без «бегущих строк» (у e-ink нет частичных обновлений).
- **Разделители** — пунктирная линия между невыделенными строками
  (читается как «серая» на 1-bpp); рядом с выделением не рисуются.
- **Диалоги** — один стиль: экран очищается, белая скруглённая карточка
  (r=20), заголовок, до четырёх строк текста, две pill-кнопки: OK
  залитая (первичная), ОТМЕНА контурная. Углы всех скруглений гладкие
  (roundFrame = заливка + выемка, не построчные кольца).
- **Прогресс** — пилюли (скруглённые полосы) на всю ширину контента;
  слабые места — контурные чипы с переносом по ширине.
- **Display56** — крупный шрифт для постерных моментов: процент в Summary,
  «LingoInk» на карточке выключения, вордмарк на splash.
- **Шрифты**: title36 (заголовки), ui22 (Inter SemiBold — статусы,
  счётчики, подписи), body28/body28b (текст), display56 (постеры).

Смотреть без прошивки: `bash tools/preview/run.sh` — рендер всех экранов
в `out/preview/*.png` (те же Canvas/Chrome, что в прошивке); основной
вид — портрет 180 (`*_o3.png`).

## Ориентация

Единственная ориентация — **Портрет 180°** (480×800, «книжный хват»):
выбрана пользователем как правильная и единственная. Технически буфер
всегда панельный 800×480, портрет — трансформация координат в Canvas;
поддержка 4 поворотов в коде осталась (используется превью), но
прошивка всегда стартует в портрете 180°.

## Refresh strategy

Утверждено пользователем на железе:

- Все обновления в сессии — **FAST DU** (~85 мс): движение курсора,
  фидбек ответа, смена фаз и экранов.
- **FULL refresh** происходит только: на карточке выключения, по
  CLEAN SCREEN NOW, при смене ориентации и после RESET PROGRESS, плюс
  автоматически — если пользователь включил Auto Clean (каждые 20/40
  обновлений). По умолчанию автоматика выключена.
- Boot без полного обновления — быстрый вход в меню.
- Правило для новых фич: никаких анимаций и миганий; «движение» =
  инверсия строки; текстовые страницы листаются как в читалке.

## Lock screen / выключение

- Power или 10 мин простоя → сохранение прогресса → свежий замер заряда
  (BatteryMonitor, не кеш меню) → карточка-заставка «LingoInk /
  Английский · Русский / Один экран. Одна цель» + внизу «Заряд N%»
  (тот же артворк, что и сплэш при включении; замер недоступен — строка
  не рисуется) (FULL refresh) → rails off → deep sleep. Во сне экран
  не обновляется — хранит измеренное перед выключением значение.
- Пробуждение — только кнопка Power (холодный boot ~1 c до splash).
  Промежуточного lock screen с быстрым возвратом нет — это осознанное
  упрощение MVP; карточка выключения и есть «экран ухода».

## Языки интерфейса

Язык обвязки UI (CONTINUE/ВЕРНО/НАСТРОЙКИ…) переключается в Settings →
LANGUAGE: English или Русский; выбор сохраняется, по умолчанию —
Русский (аудитория ru→en). Пользовательский контент живёт в курсе на SD
и не зависит от языка обвязки. Кириллица и латиница есть в шрифтах;
других скриптов пока нет (новый язык — субсет через `tools/make_font.py`
плюс таблица строк в `src/ui/Strings.h`).
